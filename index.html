Подключение Supabase

1

Создай бесплатный проект

Открой supabase.com/dashboard, нажми New project, придумай название и пароль базы. Регион выбери ближайший. Дождись запуска проекта.

2

Создай таблицы и правила безопасности

В панели Supabase открой SQL Editor → New query. Скопируй весь код ниже, вставь и нажми Run.


        
3
Включи вход через Google
  1. Открой Authentication → Providers → Google.
  2. Включи Google и вставь Client ID и Client Secret, созданные в Google Cloud.
  3. В URL Configuration добавь адрес этого приложения в Redirect URLs.
Для первого теста можно оставить только вход по email, но перед настоящим запуском владельцем аккаунтов и проекта должен быть родитель или другой взрослый.

        
4
Скопируй URL и публичный ключ
Открой Project Settings → API Keys. Нужны только Project URL и ключ Publishable, начинающийся с sb_publishable_. Ключи Secret и service_role сюда вставлять нельзя.
Сейчас приложение работает с демонстрационными данными.
<meta name="supabase-url" content="ВСТАВЬ_URL">
<meta name="supabase-publishable-key" content="ВСТАВЬ_PUBLISHABLE_KEY">
После вставки значений скачай обновлённый файл или замени эти две строки в начале index.html.
